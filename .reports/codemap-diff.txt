Deviation from the skill's default file set
-------------------------------------------
backend.md -> capture.md + delivery.md, frontend.md -> ui.md.
This is an Android app with no server component; "backend" would have been a
misleading name for a BLE session state machine, and splitting capture from
delivery matches how the code is actually partitioned (ble/ vs
delivery/+network/) and where its bugs have clustered.

Architecture notes worth carrying
---------------------------------
- 7 packages: ble, data, delivery, diagnostics, network, service, ui.
- No DI framework. BasculeApplication is a lazy service locator by choice.
- Room schema is at v4 (MIGRATION_3_4 added permanentRejectionHttpCode).
- WorkManager is the only scheduler: ScaleSessionWorker, DeliveryWorker,
  DeliveryPeriodicKickWorker, ReplayMigrationWorker (built, unwired).
